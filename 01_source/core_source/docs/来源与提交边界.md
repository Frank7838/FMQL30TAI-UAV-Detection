# 源码与依赖来源

src保存当前系统实现，reference保留IR部署、FPGA像素预处理和模型转换参考。代码中的寄存器地址、帧协议和模型形状对应当前开发板与模型11。

NPU和DetPostZG属于厂商平台，Icraft及器件工具由复旦微开发环境提供。third_party中直接使用的头文件保留原版权和许可。FPGA顶层代码基于厂商工程接线，项目增加的是检测结果输入、ROI判断、连续确认、超时监测和LED控制。

模型基于Ultralytics YOLO11。训练与开发数据来源、实际采用数量和分组说明在材料根03_model/DATASET_SOURCES.md。仓库不包含训练图像、标注全集或原视频数据集；文档与演示中的少量例图、片段按原来源说明用途。

软件使用的第三方许可位于材料根08_licenses_and_notices。原始实验记录留在工作目录，提交材料只保留与当前版本结论有关的结果和示例。
