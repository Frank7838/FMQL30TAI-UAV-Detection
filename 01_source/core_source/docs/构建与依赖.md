# 构建与依赖

## 板端程序

NPU程序使用AArch64工具链、Icraft 3.39、ZG330Backend、OpenCV和yaml-cpp，平台头文件还依赖Eigen、spdlog与fmt。已有配套Docker环境时，在本目录运行：

```text
python build/build_arm64.py npu
python build/build_arm64.py mmio
```

脚本指定了原构建镜像，输出写到build_output。编译器、SDK和镜像由平台开发环境提供，不放入Git。CPU取样和MPEG4编码库的编译参数见build/build_native_linux.sh；编码库需要与板端OpenCV相配的FFmpeg 4.4.4开发文件。

Python运行依赖NumPy和OpenCV。src/board/systemd有固定地址、只读查看和检测自启三项服务；02_runtime/board提供当前运行文件及会话清理更新。

## Windows上位机

使用Windows 10/11 x64和.NET Framework 4.8。构建命令：

```text
powershell -File build/build_desktop.ps1 -PythonExecutable <含PyInstaller和Paramiko的Python>
```

产物位于build_output/desktop。src/desktop包含WinForms界面和SSH组件；运行包在材料根02_runtime/Windows/UAVDetectionSystem。复制整个运行目录即可使用，私钥和个人连接设置另行配置。

## FPGA

build/alarm_sources.f列出告警RTL，build/run_alarm_sim.sh用于仿真。父工程使用Vivado 2018.3、Procise 2025.1.1及对应厂商平台文件。

本仓库保留告警RTL、顶层接线和约束。完整厂商工程、器件库和工具补丁约1.3GB，保留在本机pc_runs/submission_cleanup_20261031_v1/local_fpga_assets/04_fpga/parent_project_sources.zip，未重复放进Git。建立新环境时先准备厂商平台工程，再执行build/fpga/apply_observer_overlay.tcl接入本项目源码，约束沿用src/pl/constraints与厂商工程配套文件。现有父工程仍有继承的时序/DRC限制，数值见材料根05_evidence/实测结果.md。

板端现有模型、二进制和配套服务在材料根02_runtime中。以上构建入口生成本地文件，部署步骤见[使用与部署](../../部署说明.md)。

reference/pl_pixel/ps保留预处理的连续缓冲区、寄存器访问、CPU参考和耗时比较代码。build/fpga保留启动镜像分区模板及厂商bootgen调用。
