# 异构协同的低空无人机检测系统

2026 年全国大学生嵌入式芯片与系统设计竞赛 FPGA 创新设计赛道作品。基于复旦微 FMQL30TAI，采用 CPU、NPU 和 FPGA 协同实现无人机检测、区域告警与上位机监控。
A 2026 FPGA Innovation Track project using Fudan Microelectronics FMQL30TAI for UAV detection, zone alerts, and monitoring through CPU, NPU, and FPGA collaboration.

本作品面向固定机位的低空无人机辅助监测，使用 USB 相机采集画面，在复旦微 FMQL30TAI 悟净开发板上完成目标识别、区域告警和状态记录。板端可独立运行；Windows 上位机提供画面、状态、记录导出及认证启停。当前交付使用固定的 **模型 11**，基于 YOLO11 训练并转换为 INT8 部署模型。

## 系统如何工作

USB 相机采集可见光画面。CPU 负责采集、尺寸及颜色处理、检测结果整理和画面绘制；ZG330 NPU 执行模型 11 推理；FPGA 根据检测框完成区域判断和连续确认，维护告警状态、结果超时及事件记录。LED2 表示目标告警，LED1 表示检测结果超时。连续 3 帧命中触发告警，连续 8 帧无命中解除告警。硬件事件记录使用 100 MHz 业务时钟，每类保存最近一次的周期数与帧号。

## 运行与部署

已配置的设备接通电源、相机和网络后，可由板端服务运行；Windows 10/11 x64 上复制整个 `02_runtime/Windows/UAVDetectionSystem/` 目录，使用 .NET Framework 4.8 运行上位机。启停需在授权设备上单独配置 SSH 认证，材料不包含个人密钥或凭据。

审核副本已清除上位机默认的设备专用主机指纹并重新构建；SSH 控制组件已完成离线自检。首次使用须填写经核实的板卡指纹和私钥路径，重新构建后的上位机尚未做实际连板验收。板端提交副本也移除了已淘汰查看网页及其根路径，保留上位机使用的只读 API，并更新启动校验清单；该修改已上板验证状态接口、实时预览、正常停止及 SDK 关闭，测试后恢复检测。

重新部署需要匹配的**厂商 Linux 系统、Icraft 3.39、ZG330 运行库及配套 FPGA 平台文件**，以及相机和网络环境。更换文件系统时需重新适配设备锁并构建对应程序；具体路径、依赖和步骤见[使用与迁移说明](01_source/部署说明.md)及[构建与依赖](01_source/core_source/docs/构建与依赖.md)。厂商系统镜像、完整 FPGA 父工程和 SDK 安装包需另行获取。

## 主要实测结果

- 当前完整版本相机连续运行 **3600.122 秒**，完成 **107396 次推理与有效 FPGA 提交**，平均 **29.831 FPS**，未知状态 0，正常关闭 SDK。[一小时记录](05_evidence/camera_1h_final_result.json)保留了统计范围；主循环逐次核对，滚动日志只保留尾部。
- 模型 11 在 **1629 张已用于调试和选模的开发图像**上，实板 INT8 精确率 **95.65%**、召回率 **95.77%**、F1 **95.71%**。这些是开发及部署核验结果。
- 同组 40 张训练图像上，SDK 前向均值由 **24.36 ms 降至 11.24 ms**，输出逐字节一致；这是 SDK 调度优化，不归为新增 FPGA 计算加速。
- IR 模型和 FPGA 像素预处理作为扩展保留；当前 RGB 产品使用 CPU 预处理。详细分母、计时范围及硬件报告见[实测结果](05_evidence/实测结果.md)。

部分演示素材录制于运行优化前，画面中的帧率对应录制时版本；当前性能以最新实测为准。数据集原始图像及标签全集不随目录提交，详见[数据来源](03_model/DATASET_SOURCES.md)。视频中使用的公共片源归原作者。
