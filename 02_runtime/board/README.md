# 板端运行文件

payload以当前运行基线为基础，已包含会话清理。模型、NPU程序和FPGA告警规则保持原配置。

payload/PAYLOAD_SHA256.json由启动程序读取；RELEASE_ACCEPTANCE.json保存原运行基线验收信息。只迁移Windows电脑时不需要重新安装板端文件，操作方法见[使用与部署](../../01_source/部署说明.md)。

分发目录不附固定数据图像。probe_static、probe_alarm等数据回放入口需要另备原有验证输入；日常相机检测不需要这些图像。运行文件配套清单随分发副本同步，模型、NPU二进制和FPGA启动文件未改动。

当前完整版本相机连续运行3600.122秒，107396次推理、107396次有效FPGA提交，整段平均29.831 FPS，未知0，SDK正常关闭。有限测试参数已撤除，默认run_camera.py仍为持续运行。

提交副本移除了已淘汰的独立查看网页，并删除viewer.py中指向该页面的根路径；画面、状态、记录导出等只读API保留。PAYLOAD_SHA256.json已按副本重新计算。历史验收记录描述原运行版本，该修改已上板验证状态接口、实时预览、正常停止及 SDK 关闭。
