# 无人机检测系统使用说明

复制整个`UAVDetectionSystem`文件夹，双击`无人机检测系统.exe`。保留`engine`和许可证目录，程序可放在任意本地目录，不要求有D盘。适用于Windows 10/11 x64及.NET Framework 4.8，通常无需另装Python或SSH客户端。第二台电脑的迁移与完整操作检验已通过。

## 接线与连接设置

板卡接好相机、电源和网线，通电后自行检测。网线可以直连电脑，也可以接入路由器。

|接法|电脑与上位机设置|
|---|---|
|直连电脑|板卡`169.254.74.247`；电脑可设为`169.254.74.246`，掩码`255.255.0.0`|
|接路由器|电脑与板卡网络互通，在“连接设置”填写板卡实际地址|

画面端口为`8080`，SSH端口为`22`。查看画面不需要SSH密钥；手动启停需要已被板卡授权的私钥，并核对板卡主机SHA256指纹。新电脑填写自己的私钥路径，私钥和口令不随软件分发。

个人连接设置保存在`%LOCALAPPDATA%/UAVDetectionSystem/v2/connection.json`。目录里的连接配置示例用于说明字段，需按现场地址和本机路径填写；程序不会自动配置电脑网口或板卡授权。

## 常用操作

|操作|用途|
|---|---|
|启动检测 / 正常停止|通过SSH控制板端服务；停止时等待“已停止”及SDK关闭|
|暂停画面 / 空格键|暂停或恢复本机预览，板端检测与告警继续|
|保存画面 / Ctrl+S|保存当前JPEG预览，包含已有检测框和编号；暂停时保存暂停前的画面|
|F5|刷新运行状态，在告警记录页同时刷新记录|
|告警记录|查看最近最多100条滚动记录|
|导出记录|保存板端会话ZIP；完整录像在正常停止后导出|

关闭上位机不会停止板端检测。画面待恢复的提示仅反映预览更新情况，静态场景的相同JPEG也可能触发，需结合板端运行状态判断。

## 拍摄与记录

使用前固定相机方向，先让目标进入蓝色ROI区域观察告警。每次会话最多保存1200帧录像，达到上限后仍继续检测和预览。需要重新录制时，正常停止并确认SDK关闭，再启动新会话；结束后停止并导出记录。

导出中断可能留下`.partial`文件，再次导出时选择新文件名。检测FPS指板端处理速度，画面更新/秒指电脑预览速度；目前预览约6—7次/秒，两者不同。

审核副本已清除设备专用默认主机指纹并重新构建上位机；SSH控制组件已完成离线自检。首次使用时须填写经核实的板卡指纹和本机私钥路径，重新构建后的上位机尚未进行实际连板验收。
